## Task 3: Fix partial payment defaults to full amount

**Files:**
- Modify: `src/pages/order-create/StepPayment.tsx` — fix useEffect

- [ ] **Step 1: Fix the useEffect in StepPayment.tsx**

In `src/pages/order-create/StepPayment.tsx`, find the `useEffect` (lines ~37-50):
```ts
  useEffect(() => {
    if (form.paymentMode === 'full') {
      const today = new Date().toISOString().slice(0, 10)
      onChange({
        payments: [{
          id: form.payments[0]?.id ?? crypto.randomUUID(),
          amount: formatPriceInput(finalAmount),
          dueDate: today,
          paymentType: form.payments[0]?.paymentType ?? 'cash',
        }],
      })
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [form.paymentMode, form.applyCashback, form.totalAmount])
```

Replace with:
```ts
  useEffect(() => {
    if (form.paymentMode === 'full') {
      const today = new Date().toISOString().slice(0, 10)
      onChange({
        payments: [{
          id: form.payments[0]?.id ?? crypto.randomUUID(),
          amount: formatPriceInput(finalAmount),
          dueDate: today,
          paymentType: form.payments[0]?.paymentType ?? 'cash',
        }],
      })
    } else {
      // Partial mode: reset to one empty payment slot
      onChange({
        payments: [{
          id: form.payments[0]?.id ?? crypto.randomUUID(),
          amount: '',
          dueDate: form.payments[0]?.dueDate ?? new Date().toISOString().slice(0, 10),
          paymentType: form.payments[0]?.paymentType ?? 'cash',
        }],
      })
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [form.paymentMode])
```

The key changes:
- Added `else` branch for partial mode that resets `amount` to `''`
- Changed dependency array from `[form.paymentMode, form.applyCashback, form.totalAmount]` to `[form.paymentMode]` — the full-mode amount will now update via the `finalAmount` variable when the user manually changes cashback/total, not auto-recalculate on every render

Wait — for full mode, we DO want to recalculate when `applyCashback` or `totalAmount` changes since the amount should reflect the final payable. So keep the dependency array, just add the else:

```ts
  useEffect(() => {
    if (form.paymentMode === 'full') {
      const today = new Date().toISOString().slice(0, 10)
      onChange({
        payments: [{
          id: form.payments[0]?.id ?? crypto.randomUUID(),
          amount: formatPriceInput(finalAmount),
          dueDate: today,
          paymentType: form.payments[0]?.paymentType ?? 'cash',
        }],
      })
    }
    // In partial mode: do not override — user enters amounts manually
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [form.paymentMode, form.applyCashback, form.totalAmount])
```

But the problem is: when you SWITCH to partial mode, the previous payments array still has the full amount set. Add a separate effect for mode switch:

Replace the entire useEffect block with these two effects:
```ts
  // Recalculate full-mode payment amount whenever total or cashback changes
  useEffect(() => {
    if (form.paymentMode !== 'full') return
    const today = new Date().toISOString().slice(0, 10)
    onChange({
      payments: [{
        id: form.payments[0]?.id ?? crypto.randomUUID(),
        amount: formatPriceInput(finalAmount),
        dueDate: today,
        paymentType: form.payments[0]?.paymentType ?? 'cash',
      }],
    })
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [form.paymentMode, form.applyCashback, form.totalAmount])

  // When switching to partial mode, reset to one empty payment slot
  useEffect(() => {
    if (form.paymentMode !== 'partial') return
    onChange({
      payments: [{
        id: crypto.randomUUID(),
        amount: '',
        dueDate: new Date().toISOString().slice(0, 10),
        paymentType: 'cash',
      }],
    })
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [form.paymentMode])
```
